# Separate environment for the handful of notebooks that need OpenCV 5.x
# specifically (opencv-contrib-python-headless, not opencv-python-headless —
# the "contrib" wheel is what restores cv2.CascadeClassifier under 5.x,
# per https://github.com/opencv/opencv/wiki/OpenCV-4-to-5-migration).
#
# Setup (from repo root):
#   python3 -m venv .venv5x
#   .venv5x/bin/pip install -r requirements-5x.txt
#   .venv5x/bin/python3 -m ipykernel install --prefix="$(pwd)/.venv5x" \
#       --name python3-cv5 --display-name "Python 3 (OpenCV 5.x)"
#
# Why a second environment instead of upgrading requirements.txt for
# everything: this repo's other 39 notebooks are verified against
# opencv-python-headless==4.10.0.84, and OpenCV 5.x's DNN engine can't even
# parse notebook 34's LaMa model (DequantizeLinear op unsupported in 4.x) —
# confirmed empirically, not assumed. Splitting environments keeps the
# already-verified notebooks untouched while still letting a few genuinely
# 5.x-only notebooks exist. See the README's "OpenCV 5.x notebooks" section.
